# Exported research metrics (summary only)

The values in [`reported_study_metrics.csv`](reported_study_metrics.csv) are **transcribed summary statistics** from the original MSc analysis outputs. They were **not computed by the helper functions in this repository**. Original DIA-NN reports, target protein FASTA, full scripts and raw experimental data are not redistributed here.

The table describes candidate precursor lists, not experimentally confirmed scheduled-PRM assays. Consult the [research case study](https://github.com/Daniello333/Daniello333/blob/main/projects/prm-proteomics.md) for interpretation and limitations.
