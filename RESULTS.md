# Evidence and selected exported results

This portfolio snapshot contains minimal public-facing CSV tables and four PNG plots extracted from `WYNIKI(1).zip`, rather than the full 400 MB ZIP / >1 GB extracted results. The source exports were produced on 2026-09-04.

## Reference CSVs
- `results/summaries/in_silico_digestion_summary.csv`: four protease / missed-cleavage variants.
- `results/summaries/retention_crowding_summary.csv`: window crowding before/after candidate replacements.
- `results/summaries/precursor_lists_summary.csv`: Top 2 / Top 3 baseline and extended coverage.
- `results/summaries/irt_validation_summary.csv`: observed vs predicted 30-minute retention-time transfer errors.

The per-protein precursor-level lists, original DIA-NN Parquet data and raw LC–MS files are **not distributed** here. In the exported outputs, 741 was the design panel; the baseline experimentally supported list covered 596 and its extension covered 609.
